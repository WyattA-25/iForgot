# iForgot

AI-powered lost-item finder. Upload a photo and five custom-trained YOLOv8 detectors
locate common misplaced items (keys, wallet, headphones, glasses, earbuds) behind a
chat-style web interface.

Detectors reach mAP@0.5 of 0.99 on keys and glasses in-distribution; real-world recall
varies by item and lighting.

Source and full documentation: https://github.com/WyattA-25/iForgot
